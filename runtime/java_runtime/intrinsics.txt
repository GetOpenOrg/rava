# VM 内建函数（intrinsic）清单：公开 API 中标注 @IntrinsicCandidate、且 Java 规范规定唯一
# 精确结果的方法，允许在共置 `_impl.rs` 以等价原生运算实现（HotSpot 同样不执行其 Java 体）。
# 准入条件（全部满足）：
#   1. JDK 源码标注 @IntrinsicCandidate；
#   2. 规范给出唯一结果（IEEE 754 正确舍入 / 精确运算），Rust 原生运算逐位相同；
#   3. 在此列出并注明规范依据。
# 与「手写覆盖」（FS-H0 审计线，最终态 0）分开计数：intrinsic 是最终态的一部分。
#
# 格式：binary_name.method:descriptor    # 规范依据
java/lang/StrictMath.sqrt:(D)D           # JLS / StrictMath.sqrt：IEEE 754 squareRoot 正确舍入；f64::sqrt 同为正确舍入

# ── 运行期类定义点（第二类准入）：原生二进制无运行期类定义（defineClass / 隐藏类），
#    JDK 在此处生成字节码并定义新类的方法由 VM 承载（HotSpot 的等价物是类加载子系统本身）。
#    准入条件：方法体的唯一可观察效果是「定义并返回一个类」，VM 以类宇宙中的静态类等价承载。
java/lang/invoke/ClassSpecializer$Factory.generateConcreteSpeciesCode:(Ljava/lang/String;Ljava/lang/invoke/ClassSpecializer$SpeciesData;)Ljava/lang/Class;   # 动态物种统一由 VM 支持类 BoundMethodHandle$Species_Dyn 承载（docs/plans/2026-09-27-bmh-dynamic-species.md）
jdk/internal/reflect/MethodAccessorGenerator.generateSerializationConstructor:(Ljava/lang/Class;[Ljava/lang/Class;ILjava/lang/Class;)Ljdk/internal/reflect/SerializationConstructorAccessorImpl;   # 序列化构造器访问器统一由 VM 支持类 SerializationConstructorAccessorDyn 承载（docs/plans/2026-09-27-reflection-metadata-table.md §2.4）
# ── 栈帧查询点（第三类准入）：原生二进制无 Java 栈帧（Throwable.getStackTrace 为空）。
#    JDK 以栈帧判定异常抛出位置的方法由 VM 以等价的运行期登记应答。
#    准入条件：方法体的唯一可观察效果是「按抛出位置作布尔判定」，VM 登记与栈帧判定逐例同解。
jdk/internal/reflect/AccessorUtils.isIllegalArgument:(Ljava/lang/Class;Ljava/lang/RuntimeException;)Z   # 反射目标抛出由 L3 分派登记（reflect_dispatch::thrown_by_target）；未经目标逃逸 = 实参转换失败
