# VM 内建函数（intrinsic）清单：公开 API 中标注 @IntrinsicCandidate、且 Java 规范规定唯一
# 精确结果的方法，允许在共置 `_impl.rs` 以等价原生运算实现（HotSpot 同样不执行其 Java 体）。
# 准入条件（全部满足）：
#   1. JDK 源码标注 @IntrinsicCandidate；
#   2. 规范给出唯一结果（IEEE 754 正确舍入 / 精确运算），Rust 原生运算逐位相同；
#   3. 在此列出并注明规范依据。
# 与「手写覆盖」（FS-H0 审计线，最终态 0）分开计数：intrinsic 是最终态的一部分。
#
# 格式：binary_name.method:descriptor    # 规范依据
java/lang/StrictMath.sqrt:(D)D           # JLS / StrictMath.sqrt：IEEE 754 squareRoot 正确舍入；f64::sqrt 同为正确舍入

# ── 运行期类定义点（第二类准入）：原生二进制无运行期类定义（defineClass / 隐藏类），
#    JDK 在此处生成字节码并定义新类的方法由 VM 承载（HotSpot 的等价物是类加载子系统本身）。
#    准入条件：方法体的唯一可观察效果是「定义并返回一个类」，VM 以类宇宙中的静态类等价承载。
java/lang/invoke/ClassSpecializer$Factory.generateConcreteSpeciesCode:(Ljava/lang/String;Ljava/lang/invoke/ClassSpecializer$SpeciesData;)Ljava/lang/Class;   # 动态物种统一由 VM 支持类 BoundMethodHandle$Species_Dyn 承载（docs/plans/2026-09-27-bmh-dynamic-species.md）
jdk/internal/reflect/MethodAccessorGenerator.generateSerializationConstructor:(Ljava/lang/Class;[Ljava/lang/Class;ILjava/lang/Class;)Ljdk/internal/reflect/SerializationConstructorAccessorImpl;   # 序列化构造器访问器统一由 VM 支持类 SerializationConstructorAccessorDyn 承载（docs/plans/2026-09-27-reflection-metadata-table.md §2.4）
# ── 栈帧查询点（第三类准入）：原生二进制无 Java 栈帧（Throwable.getStackTrace 为空）。
#    JDK 以栈帧判定异常抛出位置的方法由 VM 以等价的运行期登记应答。
#    准入条件：方法体的唯一可观察效果是「按抛出位置作布尔判定」，VM 登记与栈帧判定逐例同解。
jdk/internal/reflect/AccessorUtils.isIllegalArgument:(Ljava/lang/Class;Ljava/lang/RuntimeException;)Z   # 栈帧规则「途经 java.base 帧继续、遇用户帧判目标抛出」由 L3 分派登记等价（reflect_dispatch::thrown_by_target：仅经用户成员逃逸者登记）
java/lang/reflect/Proxy.newProxyInstance:(Ljava/lang/ClassLoader;[Ljava/lang/Class;Ljava/lang/reflect/InvocationHandler;)Ljava/lang/Object;   # 运行期类定义点：动态代理类统一由 VM 支持类 Proxy$Dyn 承载（docs/plans/2026-09-27-reflection-metadata-table.md §2.6）
java/lang/reflect/Proxy$ProxyBuilder.isProxyClass:(Ljava/lang/Class;)Z   # 运行期类定义点的对偶查询：代理类即 Proxy$Dyn（不经 defineProxyClass 登记 reverseProxyCache）
# LambdaForm 编译（运行期类定义点）：JDK 把 LambdaForm 编译为隐藏类字节码（ASM + defineHiddenClass），
# 原生二进制以原生 LambdaForm 解释器承载全部句柄调用（MH-native，docs/plans/2026-09-26-mh-native.md §二-2）；
# 编译入口返回解释入口 MemberName（HotSpot interpret_<sig> 的等价物，「已就绪」判据）。
java/lang/invoke/InvokerBytecodeGenerator.generateCustomizedCode:(Ljava/lang/invoke/LambdaForm;Ljava/lang/invoke/MethodType;)Ljava/lang/invoke/MemberName;   # 生成 LambdaForm 隐藏类 → 解释入口
java/lang/invoke/InvokerBytecodeGenerator.generateLambdaFormInterpreterEntryPoint:(Ljava/lang/invoke/MethodType;)Ljava/lang/invoke/MemberName;   # 生成解释入口隐藏类 → 解释入口
java/lang/invoke/InvokerBytecodeGenerator.lookupPregenerated:(Ljava/lang/invoke/LambdaForm;Ljava/lang/invoke/MethodType;)Ljava/lang/invoke/MemberName;   # 查 jlink 预生成 LambdaForm Holder 类（运行期按名加载）→ null，走解释
