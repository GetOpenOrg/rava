# VM 根方法清单：手写运行时（runtime/java_runtime/src 下的 VM 基础设施）直接调用的
# 已翻译 Java 方法。JVM 自身也会预加载一组 well-known 类（HotSpot vmClasses），
# 这里是它的对应物：转译 BFS 把每一行作为调用链种子，保证这些方法在每次构建中都被翻译。
#
# 格式：<class binary name>.<method name>:<descriptor>，`#` 开头为注释。
# 只登记手写层真实调用的方法；新增手写层依赖时同步登记。
