# 注解实例由 JDK AnnotationParser 按原始字节解析：注解类型（AnnotationType 反射其方法 = 元素）、
# 元注解（Retention / Inherited）与枚举 / Class 元素类型只出现在注解属性体里，无静态调用边。
# 下列成员在调用链上时（注解解析入口被触达），生成器按用户类的 RuntimeVisibleAnnotations
# 传递收集这些类型入闭包：注解类型的方法入链（方法表 = 元素面），枚举元素类型的 <clinit>
# 入链并登记类初始化钩子（Enum.valueOf → 常量目录）。原则 4：类名只在本清单出现。
