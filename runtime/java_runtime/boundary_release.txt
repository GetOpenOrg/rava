# FS-R（docs/plans/2026-09-27-reflection-metadata-table.md）：VM 边界类 java/lang/Class 的纯 Java
# 嵌套辅助类（0 个 ACC_NATIVE）。Class 的反射公开方法回到字节码后经它们缓存 / 解析元数据：
# reflectionData() 缓存、EnclosingMethodInfo（isLocalClass / isAnonymousClass / getEnclosingClass）、
# Atomic（reflectionData / annotationData 的 CAS）、AnnotationData。
java/lang/Class$ReflectionData
java/lang/Class$EnclosingMethodInfo
java/lang/Class$Atomic
java/lang/Class$AnnotationData

# FS-R R2a：反射访问器族（JDK 21 的 Field.get / Method.invoke 经 ReflectionFactory →
# MethodHandleAccessorFactory → DirectMethodHandle，与 MH-native 同一管线）。包内 native
#（Reflection.getCallerClass 等）仍由共置 _impl.rs 手写；运行期字节码生成点
#（generateConstructor / generateMethodAccessor）按 intrinsics.txt 准入（R3）。
jdk/internal/reflect/

# FS-R R4b：注解解析族（JDK 21 Class/Field/Method.getAnnotation → AnnotationParser 按原始字节解析，
# 实例经 Proxy.newProxyInstance + AnnotationInvocationHandler）。纯 Java。唯一例外 parseSig
# （sun/reflect/generics 签名解析 + Class.forName）手写：注解签名恒为描述符形态，结果即
# 描述符 → Class（annotation_parser_impl.rs）——generics 包不放行（其泛型 visitor 体系使
# java_runtime 编译峰值内存越过 15G）。
sun/reflect/annotation/
