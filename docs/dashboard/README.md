# 项目进展全景看板

- **看**：浏览器直接打开 `index.html`（file:// 可用；需外网加载 D3/dagre CDN）。
- **更新**：只改 `data.js`（内容即 JSON，仅套一层 `const DASHBOARD_DATA = …;` 赋值——这样 file:// 直开不受 CORS 限制），刷新即重排——dagre 自动布局，无需动坐标。**单一数据源，零派生文件**；卡点建议文案用节点 `sug` 字段，同样只进数据。边需保持 DAG（由低列指向高列，不引入回边）。
- **结构**：`index.html`（壳）+ `data.js`（唯一数据源）+ `styles.css`（样式）+ `app.js`（逻辑）四件分离。
- **图例**：左色条=节点整体状态（绿✅完成/蓝🔄进行中/红⛔卡点/橙🟠风险/紫🟣等待触发/灰⚪排队）；节点内分段条=子任务状态；边=依赖流向（实线绿=上游已完成、蓝色流动=进行中、红虚线=被阻塞、加粗红=关键路径）；虚线框节点=该泳道已完成汇总。
- **交互**：悬停节点看链路（上下游点亮，折叠汇总节点会把成员链路一并点亮）；悬停边加粗高亮并点亮两端节点（其余边压暗）；点击看详情与卡点影响分析；顶栏状态筛选；「折叠已完成」开关（默认开：done 工作节点按泳道收成汇总，里程碑/上下文保留）；关键路径开关；DAG/状态板切换；滚轮缩放拖拽（缩放域 0.05–8）；底部卡点清单默认折叠成标题栏，点击展开。边带方向箭头（随边着色）。
- 数据为静态策展（测试机线会话，2026-10-14）；后续可接 cluster_results/tasks.md 自动化。
