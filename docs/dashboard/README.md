# 项目进展全景看板

- **看**：浏览器直接打开 `index.html`（file:// 可用；需外网加载 D3/dagre CDN）。
- **更新**：只改 `data.js`（内容即 JSON，仅套一层 `window.RAVA_DATA = …;` 赋值——这样 file:// 直开不受 CORS 限制），刷新即重排——dagre 自动布局，无需动坐标。**单一数据源，无任何需要同步重建的派生文件。**
- **结构**：`index.html`（壳）+ `data.json`（数据源）+ `data.js`（同数据的脚本封装，file:// 直开用）+ `styles.css`（样式）+ `app.js`（逻辑）四件分离；`dashboard.html` 为内联合并版（预览/分发用）。
- **图例**：左色条=节点整体状态（绿✅完成/蓝🔄进行中/红⛔卡点/紫🟣等待触发/灰⚪排队）；节点内分段条=子任务状态；边=依赖流向（实线绿=上游已完成、蓝色流动=进行中、红虚线=被阻塞、加粗红=关键路径）。
- **交互**：悬停看链路（上下游点亮）；点击看详情与卡点影响分析；顶栏状态筛选；关键路径开关；DAG/甘特切换；滚轮缩放拖拽。
- 数据为静态策展（测试机线会话，2026-10-14）；后续可接 cluster_results/tasks.md 自动化。
